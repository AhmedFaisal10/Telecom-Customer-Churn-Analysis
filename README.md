# 📊 Customer Churn Analysis Portfolio

## 🔍 Overview
This repository contains **two independent customer churn analysis projects**, each built using a different analytics tool and a different dataset.  
The aim of this portfolio is to demonstrate the ability to analyze customer churn using multiple tools while delivering clear, business-oriented insights.

Each project is fully self-contained, including its own dataset, analysis process, and dashboard.

---

## 📌 Projects Included

### 🔹 1. Customer Churn Analysis (Excel)
**Tool:** Microsoft Excel  
**Dataset:** Telecom customer churn dataset (Excel-specific)

**Key Focus Areas:**
- Customer demographics and age segments  
- Contract types and churn behavior  
- Churn reasons and competitor analysis  
- Usage and consumption patterns  
- Interactive Excel dashboard using Pivot Tables and charts  

📂 Project details available in:  
`/excel-churn-analysis/README.md`

---

### 🔹 2. Customer Churn Risk Analysis (Power BI)
**Tool:** Power BI  
**Dataset:** Telecom churn dataset (Power BI–specific)

**Key Focus Areas:**
- Overall churn rate and customer risk analysis  
- Contract type, tenure, and service impact  
- Payment methods and internet service analysis  
- Revenue loss due to churn  
- DAX-based KPIs and interactive dashboards  

📂 Project details available in:  
`/powerbi-churn-analysis/README.md`
